Lumen

A KVM hypervisor platform by Quartz Systems.

This host serves the package repository that installed Lumen appliances update from. There is nothing to download here by hand — an appliance is installed from the ISO on the releases page and configures this repository itself.

Updating an appliance

Open the management console and go to System → Updates. Lumen keeps two decisions apart on that page, on purpose:

  • Updates — Lumen's own packages and the rest of the system. These never move the kernel.
  • Kernel and storage modules — the kernel and the modules built against its ABI, which move as one set and only after the package manager has confirmed it can move all of them together.

Adding the repository by hand

Only needed on a node that was not installed from a Lumen ISO.

rpm --import https://lumen.quartz.systems/RPM-GPG-KEY-lumen
dnf install https://lumen.quartz.systems/repo/stable/10/x86_64/lumen-repo-0.3.0-1.el10.noarch.rpm

Every package here is signed, and so is the repository index. An appliance verifies both before it installs anything.
