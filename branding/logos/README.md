# Lumen — logo assets (option 3a)

Sub-brand of Quartz Systems. Mark = three isometric layers (guest VM lifted in bright green over hypervisor/host planes), evenly spaced.

## Files
- lumen-mark.svg — mark for dark backgrounds (top #4dffb2, layers #00d992 @ 55% / 28%)
- lumen-mark-light-bg.svg — mark for white/light backgrounds (#00b07a)
- lumen-favicon.svg — square-padded mark for favicons / app icons
- lumen-lockup-dark-bg.svg / lumen-lockup-light-bg.svg — horizontal lockup, mark + "Lumen"
- png/ — raster renditions (text pre-rendered, no font needed)

## Notes
- Lockup SVGs set the wordmark in JetBrains Mono Bold via <text>; the font must be available where the SVG renders. Use the PNGs (or convert text to outlines) where it isn't.
- Wordmark: JetBrains Mono 700, title case "Lumen". No "Quartz Systems" eyebrow in the lockup.
- Clear space: half the mark height on all sides. Minimum lockup height 24px; below that use the mark alone.
- Colors from Quartz tokens: --qz-green-300 #4dffb2, --qz-green-500 #00d992, --qz-green-600 #00b07a, ink #0b0d12, text #f2f3f5.
